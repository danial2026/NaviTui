## Install

```sh
pip install "navitui[integrations] @ git+https://github.com/danial2026/NaviTui"
```

First launch asks for your server URL, username, and password.

## Keybindings

Press `?` for the full cheatsheet.

| key | action | key | action |
| --- | --- | --- | --- |
| `space` | play/pause | `s` | shuffle |
| `n`/`b` | next/prev | `r` | repeat |
| `←`/`→` | seek 5s | `m` | mute |
| `-`/`+` | volume | `z` | zen mode |
| `/` | search | `ctrl+g` | switch server |
| `a` | enqueue | `f` | star |
| `d` | download | `L` | lyrics |
| `q` | quit | `?` | help |
